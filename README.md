The aim of this project is to
	1. calculate the fill-level of a Caritas-Container used for collection of second hand clothes in Salzburg using a ultrasonic sensor
	2. send the resulting values to a server over mobile-network and display them accordingly

in order to improve route- and time-planning in the logistics-center (especially when it comes to containers with a few hours of travel distance by car), save on fuel and have an even more positive impact on the environment.

Currently, the prototype, packed into a 3D printed case, is tested in one of their containers directly on site.

Develope for the MultiMediaTechnology degree program / Salzburg University of Applied Sciences Salzburg.
