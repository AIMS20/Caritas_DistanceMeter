Online-accessible fill-level indicator for 
Caritas clothing donation bins to save 
fuel and time.

Developed using distance sensors (HC-SR04), an ESP32, and a GSM module as part of a project for the MultiMediaTechnology degree program / Salzburg University of Applied Sciences Salzburg.
